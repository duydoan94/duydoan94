## 🚀 What I do

I run **[Magnitudeminds](https://magnitudeminds.com)**, an AI engineering studio in Ho Chi Minh City. We ship production AI for Silicon Valley startups and enterprise teams: agent systems, model fine-tuning, data and inference pipelines, and the evaluation layer that keeps it all honest.

Along the way the studio started building its own things, and now I get to do the fun part: products, teams, and teaching.

| | What | The one-liner |
|---|---|---|
| 🔥 | **[Firedesk](https://firedesk.ai)** | AI workforce platform. Scale results without scaling payroll. |
| 🤖 | **AI Pods** | Managed AI engineering teams, led by an architect who owns the outcome. |
| 🎓 | **AI-native talent** | Agentic coding masterclasses and an intern program that treats AI agents as a first-class engineering tool. |
| ✍️ | **A book** | A memoir about building all of this without the right credentials. Coming soon. |

- 🧠 Currently obsessed with: multi-agent orchestration, agentic coding workflows, and making offshore teams feel like they sit next to you
- 🌏 Working with teams from Saigon to San Francisco, mostly while one of us should be asleep
- 💬 Say hi about anything AI, startups, or building from Southeast Asia
